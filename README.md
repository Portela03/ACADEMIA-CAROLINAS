# Academia Carolinas

## Sobre o Projeto

A Academia Carolinas é uma organização social localizada na Cidade Tiradentes, São Paulo, dedicada a promover segurança alimentar, educação e desenvolvimento comunitário. Atendemos mais de 1.000 pessoas mensalmente através de diversos programas e iniciativas sociais que visam transformar vidas e fortalecer a comunidade local.

## Nossa Missão

Transformar vidas na Cidade Tiradentes através de ações sociais integradas, promovendo dignidade, educação e desenvolvimento sustentável para famílias em situação de vulnerabilidade.

## Principais Programas

### Segurança Alimentar
- Cozinha comunitária que serve mais de 400 refeições diárias
- Distribuição de cestas básicas para famílias em vulnerabilidade
- Horta comunitária para produção de alimentos orgânicos

### Educação e Cultura
- Atividades de contraturno escolar
- Reforço acadêmico para crianças e adolescentes
- Oficinas culturais e cursos de capacitação

### Desenvolvimento Comunitário
- Cursos profissionalizantes
- Apoio ao empreendedorismo local
- Atividades de fortalecimento de vínculos comunitários

## Nosso Impacto

- **120.000+** refeições servidas por ano
- **1.000+** pessoas beneficiadas mensalmente
- **250+** crianças em atividades educacionais
- **100+** voluntários ativos

## Estrutura do Projeto Web

Este repositório contém o site oficial da Academia Carolinas, desenvolvido com as seguintes tecnologias:

- HTML5
- CSS3
- JavaScript (vanilla)
- FontAwesome para ícones

## Como Contribuir

### Para Desenvolvedores
1. Faça um fork deste repositório
2. Crie uma branch para sua feature (`git checkout -b feature/nova-funcionalidade`)
3. Faça commit das suas alterações (`git commit -m 'Adiciona nova funcionalidade'`)
4. Envie para a branch (`git push origin feature/nova-funcionalidade`)
5. Abra um Pull Request

### Para Voluntários e Doadores
Se você deseja contribuir com nosso trabalho social:

- **Doações**: Contribua financeiramente ou com doações de alimentos, materiais e equipamentos
- **Voluntariado**: Doe seu tempo e habilidades para ajudar em nossas atividades e projetos
- **Parcerias**: Sua empresa pode se tornar parceira e apoiar nossas iniciativas
